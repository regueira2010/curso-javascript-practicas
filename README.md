# 🚀 Prácticas de JavaScript - Curso de Formación

Este repositorio contiene la resolución de los 9 ejercicios prácticos propuestos durante mi formación en JavaScript. El objetivo principal es aplicar conceptos fundamentales del lenguaje, desde la manipulación básica de alertas hasta algoritmos de ordenamiento y manejo de objetos.

## 📁 Contenido del Repositorio

El proyecto está organizado por carpetas, cada una correspondiente a un ejercicio específico del programa:

1.  **Ejercicio 01:** Introducción y primer "Hola Mundo".
2.  **Ejercicio 02:** Juego de Piedra, Papel o Tijera con lógica de control (If/Else).
3.  **Ejercicio 03:** Cálculo del área de un círculo (Manipulación de Math y DOM).
4.  **Ejercicio 04:** Identificador de días del mes mediante arreglos y condicionales.
5.  **Ejercicio 05:** Algoritmo de Ordenamiento Burbuja para identificar mayor y menor.
6.  **Ejercicio 06:** Función para cálculo de montos con IVA y descuentos aplicados.
7.  **Ejercicio 07:** Juego de "Adivina el número" con control de intentos y validaciones.
8.  **Ejercicio 08:** Simulador de Identificador de Llamadas usando estructuras de objetos.
9.  **Ejercicio 09:** Contador de vocales en palabras mediante funciones expresivas y métodos de cadena.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura de las páginas de ejercicios.
* **JavaScript (ES6+):** Lógica de programación, algoritmos y dinamismo.
* **Git:** Control de versiones para el seguimiento del progreso.

## 🔧 Cómo visualizar las prácticas
1. Clona el repositorio.
2. Abre el archivo `index.html` de cualquier carpeta en tu navegador preferido.
3. Algunos ejercicios requieren interactuar con la consola del desarrollador (F12) o cuadros de diálogo (`prompt`/`alert`).
